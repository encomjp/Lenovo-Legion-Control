# Changelog - 0.2.15 (2026-09-30)

## AppImage Runs on Older Distros (glibc 2.35+)

- **Built on Ubuntu 22.04**: the AppImage is now built on the oldest supported Ubuntu LTS, so it only needs glibc 2.35 on the host (Ubuntu 22.04+, Debian 12+, Fedora 36+, and similar). 0.2.14 required glibc 2.39.
- **GTK 4.14 / libadwaita 1.5 bundled from source**: GLib 2.80, Wayland 1.23, GTK 4.14 and libadwaita 1.5 (plus AppStream 1.0 / libxmlb) are built from source in CI and bundled, since the 22.04 system versions are too old. The build is cached, so later builds stay fast.
- **SVG icons**: the librsvg pixbuf loader is now bundled so SVG icons render on systems without it.
- **CI check on 22.04**: the self-contained check now runs in a clean Ubuntu 22.04 container and also fails on missing glibc symbols.

No functional changes to the daemon, CLI or GUI compared to 0.2.14.
