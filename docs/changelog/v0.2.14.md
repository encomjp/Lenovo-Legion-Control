# Changelog - 0.2.14 (2026-09-29)

## AppImage Is Now Self-Contained

- **Bundled GTK4 / libadwaita**: the AppImage now ships GTK4, libadwaita and their dependencies (via `linuxdeploy` + the GTK plugin). Previously `legion-settings` failed to start on systems without `libadwaita-1.so.0` installed (`error while loading shared libraries`). Only base host libraries (glibc, X11/GL, fonts) are taken from the system, as usual for AppImages.
- **CI check**: the release workflow now extracts the AppImage in a clean Ubuntu container without GTK/libadwaita and fails if any bundled binary has unresolved libraries.

No functional changes to the daemon, CLI or GUI compared to 0.2.13.
