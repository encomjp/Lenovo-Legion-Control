# Changelog - 0.2.20 (2026-10-14)

Major GUI revamp. Every page was redesigned to be calmer and easier to read: one button style, plain wording, and no scrolling at the default window size. This release also adds a custom fan curve, a new tray menu and KDE widget, and several fixes found through fleet telemetry. Tested on a Legion Pro 7 16AFR10H (83RU).

## New

- **Redesigned app**: every page was rebuilt around what you need at a glance.
  - The Control center shows power mode, temperatures, fans and battery, plus four quick toggles. Details moved to tooltips and their own pages.
  - One button design everywhere, with visible outlines also when a button is unavailable, and the reason shown next to it.
  - Plain words instead of technical terms ("Background service", "Keyboard lighting is working", "Draining 9.8 W").
  - Advanced controls sit behind "Advanced" so the default view stays short.
  - Works in light and dark themes; the window no longer grows wider than the screen.
- **Custom fan curve**: draw your own temperature to fan speed curve per power mode on the Cooling page.
  - The selector opens on the power mode that is active now, so it is clear which curve you are editing.
  - Above 90 °C every fan runs at full speed, and any sensor error hands control back to the firmware.
- **Lighting**: brightness is shown in percent, a preview strip shows the current colour and effect, and duplicate brightness sliders are gone.
- **Tray menu and KDE widget**: clearer labels ("Fans: Idle", "Keyboard light: High"), grouped entries, and full mode names.
- **Idle fans**: fans stopped by the firmware's quiet mode now read "Idle" instead of "0 rpm".

## Fixes

- **NVIDIA GPU temperature**: the background service can read the dedicated GPU again. Its sandbox blocked the device, which also made the fan curve fall back to the firmware.
- **Fans staying off**: the service no longer re-sends "automatic" to fans that are already automatic. On Gen 10 firmware this could keep fans stopped for longer.
- **AMD tuning driver**: "Install" in Settings now works on source installs. The installer always ships the driver source; building it stays optional.
- **Installer**: a system-wide install removes old copies in `~/.local/bin` that could shadow the new version.
- **Welcome screen**: release highlights show as short plain text instead of raw formatting.
