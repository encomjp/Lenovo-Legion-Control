# Changelog - 0.2.4 (2026-08-30)

## Fixes

### In-app update for `/usr/local` installs

- Source copies staged by `./install.sh` were detected as a tarball install. v0.2.3 shipped no `x86_64.tar.gz`, so **Update now** stayed disabled and the dialog only had **Later**.
- Source trees can update in-app: fetch the release tag, rebuild, and install with one password prompt.
- Portable `legion-control-<ver>-x86_64.tar.gz` is now a release asset.

### Update dialog

- Wider window with **Release** and **What's new** tabs instead of a tall narrow wall of notes.
- Release tab shows `vX → vY`, one-line summary, and **Update now** / **Later**.
- Changelog lives on the second tab.

## Notes

- In-app update from 0.2.0+ applies normally.
