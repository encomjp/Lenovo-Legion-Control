# Changelog - 0.2.1 (2026-08-30)

## Fixes

### Daemon keyboard RGB (Spectrum) on systemd ≥256

- Add `DeviceAllow=char-hidraw rw` so the root daemon can open `/dev/hidraw*` for keyboard brightness and RGB. The path glob alone is ignored by systemd’s device cgroup and blocked keyboard control via IPC (`legion-cli kbd`, GUI lighting).

### Fleet fault false positives

- **`throttled_without_heat`**: only fire when the CPU is genuinely cool (~10°C below the thermal restore point), not when the governor is holding a cap in the 81–85°C hysteresis band after load.
- Per-CPU `cpuinfo_max_freq` cap threshold (from v0.1.6) unchanged — IdeaPad APUs parked at their own max no longer trip the fault.

### Device identity

- Pretty-print laptop **CPU** names from `data/cpu-ids.yaml` (SKU token in `/proc/cpuinfo`).
- Pretty-print laptop **GPU** names from `data/gpu-ids.yaml` (PCI ID lookup; ~220 NVIDIA + AMD laptop IDs).

## Notes

- Source installs: `systemctl daemon-reload && systemctl restart legion-control` after upgrade so the new unit takes effect.
- In-app update from 0.2.0 applies normally (AppImage / native packages).
