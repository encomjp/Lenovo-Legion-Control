# Changelog - 0.2.3 (2026-08-30)

## Fixes

### LOQ / IdeaPad fan RPM at idle

- Prefer the `yogafan` tachometer whenever `lenovo_wmi_other` is bound but reads 0 RPM, even if yogafan is also idle at 0.
- 2025 LOQ 15AHP10 (83JG) binds WMI with a locked IT5508 tach; real RPM is yogafan (`EC 0xFE/0xFF`). Waiting for a nonzero sample left telemetry at `rpm: null` and `fan_rpms_readable` failed 100% of the time on idle machines.
- Also includes the unreleased 0.2.2 daemon GPU fix below (0.2.2 was never published).

### Home GPU card showed "—" after boot (from 0.2.2)

- Daemon systemd cgroup blocked NVML because driver 610 needs `/dev/nvidia-caps`. Add `DeviceAllow=char-nvidia-caps rw`.
- Settings Home card falls back to a user-side nvidia-smi read if the daemon still reports no dGPU temp.
- Chip titles no longer ellipsize to `C…` / `BATTE…`.
- Unavailable dGPU / EC temps in the CLI print as `—` instead of `-1.0°C` / `0.0°C`.

## Notes

- After a source install, `systemctl daemon-reload && systemctl restart legion-control`.
- In-app update from 0.2.0+ applies normally.
