# Changelog - 0.2.12 (2026-09-03)

## Telemetry Schema v4 & Expanded Fleet Insights

- **Schema v4 Reports**: Diagnostics reports now carry `schema_version: 4` (`REPORT_SCHEMA_VERSION` in `src/diagnostics.rs`); the collector accepts schemas 1–4 so older clients keep flowing during rollout.
- **Live Power & Charging Info**: New `power` block with AC adapter status (`ac_online`, `ac_type`), live `charge_rate_w`, `charge_state`, and `voltage_v` for fleet-wide charging-behavior triage.
- **CPU Frequency Policy**: New `hardware.cpu` fields capture `governor`, `energy_performance_preference`, `scaling_driver`, `pstate_mode`, and `boost_enabled` alongside core counts and clocks.
- **Platform Profile Choices**: Reports now include the full platform-profile `choices` plus ACPI `acpi_choices` and the `current` profile, so unsupported-profile fleets are visible server-side.
- **Display & Audio Health**: New `hardware.display` `connector` and `vrr_capable` fields; new `audio` block records speaker amp health (`amp_present`, `amp_bound`, `firmware_ok`, `health`, mute/sink state) for the AW88399 fleet check.
- **dGPU Power Envelope**: New `hardware.gpu` fields record `power_limit_w`, `power_max_w`, `power_default_w`, `dynamic_boost_headroom_w`, and `pstate` for NVIDIA power-triage without touching `nvidia-smi -q` on minute pushes.

## Collector Unification & Security Hardening

- **Single Canonical Collector**: `server/collector.py` and `lenovo-legion-tool/server/collector.py` are unified to one implementation — one FastAPI app with a `lifespan` manager (`init_db` + hourly retention worker), per-request connections instead of a shared write handle.
- **Streaming Gzip with Bomb Guard**: `Content-Encoding: gzip` / `x-gzip` bodies are decompressed via streaming `gunzip_capped()` capped at `MAX_BODY_BYTES = 512 KiB`; over-cap returns 413, corrupt/truncated streams return 400, unknown encodings return 415.
- **Shared-Secret Auth**: Optional `X-Legion-Telemetry-Key` header validated with constant-time `hmac.compare_digest` when `LEGION_TELEMETRY_KEY` is set (401 on mismatch).
- **Rate Limiting & Retention**: Sliding-window per-IP limit (`LEGION_TELEMETRY_RATE_PER_MIN`, default 30/min, 429 beyond) and hourly pruning of reports older than `RETENTION_DAYS` (default 90).
- **SQLite Hardening**: WAL mode with `busy_timeout=5000` and 5 s connect timeout for concurrent daemon/GUI-adjacent writes; `GET /health` now returns `{ok, count, last_id}`.

## Privacy Enforcement & Hardware De-identification

- **Battery Serials Excluded**: The deep power dump skips any `*serial*` sysfs file and raw `uevent` snapshots — battery serial numbers never leave the machine.
- **GPU Identifiers Redacted**: The `nvidia-smi -q` deep dump redacts `GPU UUID`, `Serial Number`, `GPU Part Number`, and `GPU PDI` lines to `[REDACTED]` (cap raised to 32 KB for the sanitized dump).
- **SMBIOS UUID Pseudonymization**: The DMI product-UUID machine-ID fallback is no longer stored raw; a salted 128-bit FNV-1a `hash_to_pseudonym()` mints a deterministic UUIDv4-shaped pseudonym that survives wipes without exposing the factory UUID.

## Hardware & Daemon Fixes

- **Dynamic CPU Frequency Bounds**: The thermal governor replaces the hardcoded `MAX_FULL`/`MIN` clamp with live `cpuinfo_max/min_freq` sysfs bounds (`compute_target_dynamic`, `read_cpu_freq_bounds`, `restore_full_speed`) — throttle floors and restore caps now match the actual SKU instead of assuming the 9955HX3D envelope. Shutdown and governor-disable paths restore the real full speed.
- **Yogafan Initialization Order**: The daemon probes and auto-loads `yogafan` *before* device detection so the fan-backend `OnceLock` binds to the working tachometer on LOQ 83JG/R8CN instead of locking onto the all-zero `lenovo_wmi_other` reading.
- **Limiter Bracket Parser**: The charge-types anomaly message parses `[…]` selections via `split(']').next()` instead of `trim_end_matches(']')`, so trailing content after the bracket no longer leaks into fault text.
- **Sensor Caching**: The hwmon lookup cache gains a 5-second TTL with negative-lookup caching — hot paths avoid rescan storms while freshly appearing devices are still picked up within seconds.
