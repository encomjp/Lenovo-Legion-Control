# Changelog - 0.2.23 (2026-10-15)

A maintenance release from an overnight run on a Legion Pro 7 16AFR10H (83RU): the background service is now much quieter and easier on your SSD.

## Fixes

- **Far less logging**: the service wrote about 36,000 log lines in one night. Routine sensor readings are now summarised once a minute, and healthy keyboard-lighting and speaker checks are no longer logged. Problems are still logged as warnings.
- **No false warnings**: the keyboard-lighting check no longer warns every few seconds when the kernel log simply has no lighting errors.
- **Fewer disk writes**: the settings file is only rewritten when something actually changed, instead of about every 30 seconds.
- **Fans left alone**: setting a fan to automatic when it already is no longer writes to the firmware. On Gen 10 laptops this could keep the fans stopped for longer.
