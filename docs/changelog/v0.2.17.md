# Changelog - 0.2.17 (2026-10-14)

GPU MUX, 4-zone RGB, speaker firmware and signed updates. Tested on a Legion Pro 7 16AFR10H (83RU): 271 unit tests, 59/59 live hardware tests, 25/25 self-checks, a headless GUI smoke test of all 16 pages, and the new GPU-mode, firmware and Fn Lock paths on real hardware.

## New

- **GPU mode (MUX)**: switch between Hybrid and dGPU-only from Settings → CPU → Features or with `legion-cli gpu-mode hybrid|dgpu --yes-i-understand`. The change applies after a reboot.
  - Uses the firmware's GameZone method through `acpi_call`. A one-click "Load acpi_call" button is provided; the module itself comes from your distribution's `acpi_call` package.
  - Enabled only on verified models (SMCN BIOS family for now). It refuses Hybrid when the integrated GPU's driver is missing or disabled, which would leave a black screen, refuses on battery below 20%, and needs explicit confirmation.
  - Recovery if the screen stays black: press F2 at boot and change the graphics mode in the BIOS.
- **4-zone RGB keyboards** (Legion 5 / 5 Pro 2020–2024, IdeaPad Gaming 3, LOQ): static colours per zone, breath, wave and smooth effects, speed and brightness, in the Lighting page or with `legion-cli zones …`.
  - Commands are only sent to a controller whose HID descriptor confirms the 33-byte 4-zone report.
  - **Experimental**: packets match four reference implementations byte-for-byte, but have not been confirmed on a 4-zone laptop yet. Feedback welcome.
- **Speaker firmware**: on Gen 10 laptops with the AW88399 smart amp, Settings → Fix → Speakers and `legion-cli audio-fix` can now install the missing `aw88399_acf.bin`.
  - The firmware is not redistributable, so the app downloads it from its upstream source, checks a pinned SHA-256, and never overwrites an existing file.
  - The speakers work after a reboot or a driver reload.
- **Signed updates**: release files are signed with minisign (key `BFB503AB2424D545`).
  - The in-app updater now refuses unsigned or mismatched files, downgrades and non-HTTPS downloads.
  - It re-checks the file in a root-only staging directory right before installing.
  - Updating from 0.2.16 works as before; signatures are enforced from 0.2.17 onwards.

## Fixes

- **First-time setup** no longer fails with "required tool not found: dkms" on fresh installs.
  - The AMD tuning backend is offered only where Curve Optimizer is validated, and pre-selected only when `dkms` and your kernel headers are installed. Otherwise the exact install command is shown.
  - A failed optional step is reported as a warning while the rest of setup completes.

## Telemetry

- **Hardware-based device ID**: the anonymous telemetry ID is now a one-way hash of the firmware's hardware ID, so a reinstall no longer looks like a new laptop. The previous random ID is sent once so history can be linked. Details are in the README.
- **Fan evidence**: reports now say whether fan speeds come from an estimated embedded-controller reading. The hourly report includes the raw values of each candidate reading method next to the CPU temperature. This lets the "(est.)" readings be verified across many laptops.
