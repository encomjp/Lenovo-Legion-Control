# Changelog - 0.2.2 (2026-08-30)

## Fixes

### Home GPU card showed "—" after boot

- Daemon systemd cgroup blocked NVML (`Failed to initialize NVML: Unknown Error`) because driver 610 needs `/dev/nvidia-caps`. Same class of bug as hidraw: path globs are ignored.
- Add `DeviceAllow=char-nvidia-caps rw` so `nvidia-smi` works inside the daemon.
- Settings Home card also falls back to a user-side nvidia-smi read if the daemon still reports no dGPU temp.

### Truncated metric card titles

- Chip titles (`CPU`, `Battery`, `Fan · CPU`, …) no longer ellipsize to `C…` / `BATTE…`.

### CLI sensor display

- Unavailable dGPU / EC temps print as `—` instead of `-1.0°C` / `0.0°C`.

## Notes

- After a source install, `systemctl daemon-reload && systemctl restart legion-control` so the unit picks up nvidia-caps.
- In-app update from 0.2.0+ applies normally.
