# Changelog - 0.2.11 (2026-09-02)

## Fixes

- **AppImage Staging Skew & Daemon Update**: Fixed an issue where running from an AppImage would execute stale previously-staged helper binaries without updating `/usr/local/bin/legion-daemon`, causing the daemon to remain stuck on older versions (e.g. v0.2.8). The setup workflow now always restages bundled daemon, helper, Polkit policy, and systemd units.
- **Daemon Socket Permissions & IPC Connection**: Bound `/run/legion-control.socket` with mode `0666` and automatic `legion` group creation in `setup-helper`, preventing client `Permission denied (os error 13)` for non-root desktop users.
- **IPC Error Transparency**: Fixed error masking in `send_command` where `PermissionDenied` on the root socket was masked by `NotFound (os error 2)` from fallback socket paths.
- **Model Detection (Legion Y7000P IRX9)**: Added official model profile for `83DG` (`Legion Y7000P IRX9`, `NMCN` BIOS) with dual Coldfront fans and WMI3 platform profiles.
- **Intel & AMD Capability Gating**: Hid AMD Curve Optimizer UI on Intel laptops (including Y7000P i7-14700HX) and unsupported AMD processors (Cezanne / Zen 2).
- **Fan Layout Corrections**: Corrected Legion Pro 7 16IRX8H fan layout from three fans to two fans (Coldfront 5.0).
- **Battery EC State**: Cleared rapid charge mode before enabling battery conservation mode on Lenovo EC.
- **Sensor Robustness**: Added fallback support for `zenpower` k10temp drivers and multiline output handling in `nvidia-smi`.

## Telemetry & Fleet Visibility

- **Motherboard & EC Firmware**: Telemetry now captures motherboard DMI identifiers (`product_family`, `product_sku`, `board_name`, `board_version`) and `ec_firmware_release` to accelerate bring-up of new chassis revisions.
- **Keyboard Lighting Classification**: Explicitly records lighting type (`Spectrum`, `FourZone`, `White`) to distinguish monochrome backlights from multi-zone RGB.
- **Extended Hardware Inventory**: Deep diagnostics now include safe DMI sysfs dump, complete HID controller enumeration, ACPI thermal zones (`name (type)` -> temperature), and platform profile choices.
- **Uncapped Fleet Retention**: Server-side telemetry retention cap lifted from 5,000 to unlimited in ClickHouse.
