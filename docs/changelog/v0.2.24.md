# Changelog - 0.2.24 (2026-10-15)

Smoother upgrades for people coming from older versions.

## Fixes

- **Background service update after in-app upgrades**: updating a source install from inside the app (versions 0.2.13 to 0.2.23) only replaced the program files, so the service could miss newer device access, such as reading the graphics card temperature. Health now shows "Update the background service" when that happens. One click fixes it without touching package-owned files.
- **AMD tuning driver after in-app upgrades**: "Install" on Health now also finds the driver source in your Legion Control folder, so it works after an in-app update too.
- **Release downloads**: releases no longer include debug symbol packages, and the updater ignores them, so it always picks the right package for your system.
