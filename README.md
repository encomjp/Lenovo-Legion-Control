# Legion Control

Linux control app for **Lenovo Legion** laptops — fans, power modes, Spectrum RGB, and battery.

The Rust project, installer, and GitHub-facing docs live in **[`lenovo-legion-tool/`](./lenovo-legion-tool/)**.

```bash
./install.sh          # from this repo root
# or
cd lenovo-legion-tool && ./install.sh
```
